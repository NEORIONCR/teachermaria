# Simple Present · Teacher María

Práctica interactiva estática, lista para GitHub Pages. No necesita instalación, compilación, servidor de aplicación ni claves.

## Publicar en GitHub Pages

1. Descomprimí el ZIP.
2. Subí `index.html`, `.nojekyll` y este `README.md` a la raíz del repositorio. Si la carga web omite `.nojekyll`, el HTML también funciona sin ese archivo.
3. En GitHub, abrí **Settings → Pages**.
4. En **Build and deployment**, elegí **Deploy from a branch**.
5. Seleccioná la rama donde subiste los archivos (habitualmente `main`) y la carpeta **/ (root)**. Guardá.
6. Cuando termine la publicación, abrí la dirección que muestra GitHub Pages.

Si el repositorio ya tiene un sitio, colocá esta práctica en una carpeta `simple-present/` para conservar su página principal. La práctica quedará accesible agregando `/simple-present/` a la URL de ese sitio.

## Uso y funcionamiento

- Abrí `index.html` para probar la práctica localmente.
- Cinco secciones, corrección inmediata, explicaciones y resumen de progreso.
- Respuestas y borradores guardados en el navegador con localStorage; no se envían a ningún servicio.
- El progreso depende del navegador y la dirección donde se abre el sitio. No se sincroniza entre dispositivos ni se transfiere automáticamente de la versión local a GitHub Pages.
- Tipografías incrustadas: Bricolage Grotesque e Inter. La práctica no necesita descargar recursos externos.
- Diseño adaptable a móvil, navegación con teclado y opción para reiniciar.

## Estado del contenido

**Versión parcial de diseño y funcionalidad.** Incluye 33 preguntas originales, numeradas del 13 al 45. Faltan las preguntas 1–12, la guía de repaso y los ejercicios de refuerzo del archivo fuente, pendiente de volver a adjuntar. El sitio muestra esta limitación y calcula el progreso sobre las 33 preguntas disponibles.

Las preguntas abiertas se revisan por patrones; la evaluación es orientativa y puede requerir revisión docente.

## Verificación

Comprobadas selección múltiple, respuestas vacías, completar oraciones, reescritura, respuestas abiertas, recuperación al recargar, resultados y reinicio. Sin desbordamiento horizontal en anchos de 320 a 1440 píxeles.
